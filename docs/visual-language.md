# Visual language contract

Infinity's visual direction is editorial, calm, art-forward, and restrained. Prefer selective translucency over blanket blur. Dark and light themes must have equal care.

Shared tokens live in theme JSON and generated Quickshell/Hyprland/app integration files. QML surfaces should consume generated token files rather than hardcoding palettes.

Core motifs:

- spacious rhythm with compact controls
- soft rectangular radii, not pill-only monoculture
- strong typography hierarchy
- functional motion and clear state transitions
- original vector/wallpaper assets with license metadata
