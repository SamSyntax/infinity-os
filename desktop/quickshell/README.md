# Quickshell shell

`shell.qml` creates one scene per screen. The scene combines a background layer, editorial rail, exclusive popup controller, executable launcher, network detail, calendar, system controls, OSD, theme switcher, and wallpaper switcher.

- `services/` owns global time, theme, motion accessibility, and OSD state.
- `components/` contains small visual primitives.
- `surfaces/` owns one window or interaction surface per file.
- `~/.config/quickshell/generated/theme.json` is generated by `infinity-theme`; `Theme.qml` supplies a safe dark fallback before that file exists.
- Navbar panels share one active-panel state. Opening another replaces the current panel; Escape, a repeated navbar click, or an outside click closes it.
- Theme cards preview in memory and commit through the atomic runtime copy of `infinity-theme`. Wallpaper choices use the same transaction boundary and crossfade on change.
- `Network.qml` reads the active interface counters from sysfs, discovers its local gateway through fixed `nmcli` arguments, and probes only that gateway at a restrained cadence. Missing, measuring, and available telemetry remain distinct states.
- `CalendarSurface.qml` builds a Monday-first month grid with JavaScript `Date`; it starts at the current month whenever reopened and needs no subprocess or calendar dependency.
- `WallpaperArchiveTable.qml` maps the six wallpaper IDs to their SVG row data and palette. Matching crop-aware overlays cover the baked-in desktop rows and animate only transforms/opacity, while the unchanged SVG remains suitable for static lockscreen use.
- `~/.config/infinity-os/shell.json` stores reduced-motion and motion-scale preferences. The motion row in the system panel toggles reduced motion.

The launcher filters its curated local index and starts packaged applications through a transient user service. Volume changes call `wpctl`; lock calls `loginctl lock-session`, preserving hypridle + hyprlock as the real security boundary. Network, battery, and power are live; Bluetooth and media still need service models.
