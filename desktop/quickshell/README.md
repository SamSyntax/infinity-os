# Quickshell shell

`shell.qml` creates one scene per screen. The scene combines a background layer, editorial rail, expandable system state, launcher shell, OSD, and animated appearance previews.

- `services/` owns global time, theme, motion accessibility, and OSD state.
- `components/` contains small visual primitives.
- `surfaces/` owns one window or interaction surface per file.
- `~/.config/quickshell/generated/theme.json` is generated by `infinity-theme`; `Theme.qml` supplies a safe dark fallback before that file exists.

The launcher currently demonstrates query, selection, empty/idle language, and keyboard architecture. Application indexing/execution and live system backends remain the next integration slice. Theme cards preview both curated editions; commit remains delegated to the atomic theme CLI.
